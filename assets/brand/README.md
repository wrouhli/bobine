# Bobine — brand assets (2026)

Bobine is an independent, MIT-licensed, open-source project. **Made by [Wahid Rouhli](https://www.wahidrouhli.com/)**.

The monochrome symbol takes visual inspiration from the creator's wider design language, but this project is not branded as a corporate product.

## Use
- `bobine-logo-black.svg`: primary wordmark on light backgrounds.
- `bobine-logo-white.svg`: reverse wordmark on dark backgrounds.
- `bobine-logo-amber.svg`: optional bright amber (#FEC90A) variant on dark backgrounds.
- `bobine-symbol-*.svg`: compact symbol-only variations.

Keep each logo monochrome. Do not stretch, distort, or add additional text to the logo. For icons smaller than 32 px, use the separately optimized favicons from the Brand Kit, not a scaled-down full wordmark.

SVG paths were recreated from the approved visual concept; please check the filmstrip and wordmark visually before shipping.
